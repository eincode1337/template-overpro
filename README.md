# LR WEB Skins system (Overpro)

Модуль страницы выбора скинов CS2 для веб-панели. Тема оформления: Overpro.

## Состав
- `module_page_skins`: папка модуля (PHP, ассеты, кэш данных скинов).

## Установка
1. Скопируйте папку `module_page_skins` в `app/modules/` вашей панели.
2. Подключите модуль в админке и укажите данные подключения к базе.

## Требования
- PHP 7.4+
- Данные скинов подгружаются из публичного CSGO-API (ByMykel).
